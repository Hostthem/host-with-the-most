# Host with the Most Agency

Website for **Host with the Most**, an event hostess and hospitality staffing agency in Buea, Cameroon.

## Pages
Home, About, Services and rates, Book (staff builder), Checkout, Confirmation, FAQ, Contact.

## Files
- `index.html` page shell, SEO tags
- `style.css` red, white and black theme
- `app.js` object-oriented app (Catalog, Cart, PricingPolicy, Order, CheckoutValidator, Router, one View class per page)
- `logo.js` embedded logo

## Change the rates
Edit the `Catalog` class in `app.js` (FRS per person per day).

## Bookings
Checkout and contact forms open WhatsApp with the details pre-filled, sent to +237 679 672 445.

## Deploy
GitHub Pages (Settings > Pages > main branch) or upload these files to Hostinger `public_html`.
